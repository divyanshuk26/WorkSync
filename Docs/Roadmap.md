# Roadmap

## P0 (Must Have)

- Authentication
- Employer Dashboard
- Employee Dashboard
- Employee Management
- Task Management
- Leave Management

Reason:
Core functionality required for a working employee management system.

---

## P1 (Should Have)

- Attendance
- Announcements
- Notifications

Reason:
Improves user experience but application can function without them.

---

## P2 (Nice To Have)

- Analytics
- Charts
- Push Notifications
- File Upload
- Dark Mode

Reason:
Future scalability and enhanced user experience.
